# Architecture Decision Records (ADR)

## Process

1. Copy `template.md` to create a new ADR
2. Set status to `Proposed`
3. After review: change to `Accepted`
4. To replace: set `Superseded by ADR-XXX`, create new ADR

## Status

| Status | Meaning |
|--------|---------|
| Proposed | Under discussion |
| Accepted | Active — follow this decision |
| Superseded by ADR-XXX | Replaced by newer ADR |
| Deprecated | No longer applies |
